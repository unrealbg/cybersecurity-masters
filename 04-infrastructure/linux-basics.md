# Linux Basics Lab

## Commands to understand

```bash
id
whoami
ps aux
systemctl --type=service
journalctl
ss -tulpn
ip addr
ip route
ls -la
chmod
chown
```

## Exercise

1. Create a non-privileged lab user.
2. Create a lab group.
3. Create a directory readable only by that group.
4. Inspect one systemd service and its logs.
5. Identify processes with listening TCP sockets.
6. Explain why each permission or service configuration matters to security.
